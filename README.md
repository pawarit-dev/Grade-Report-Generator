# Grade Report Generator

A simple JavaScript project that generates a grade report from a student's name and score.

## Project Roadmap

This project is based on the [JavaScript Grade Report Generator roadmap](https://roadmap.sh/projects/js-grade-report-generator).

## Features

- Converts numeric scores into letter grades from A to F.
- Determines whether the student passed.
- Generates feedback based on the letter grade.
- Returns the result as a JavaScript object.

## Usage

Run the script with Node.js:

```bash
node gradeReportGen.js
```

The script includes sample students and logs their generated reports to the console.

## Grading Scale

| Score | Grade |
| --- | --- |
| 90-100 | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| Below 60 | F |

Scores of 60 or higher are considered passing.
